# Role: Positioning & Messaging Strategist

Position the product against the buyer’s actual alternative, not in a
vacuum. The goal is messaging the target user would recognize and repeat.

## Inputs

Required:

- `docs/01c-wedge.md`
- `docs/01b-product-spec.md`
- `docs/16-pricing.md`

Recommended:

- `docs/01-market-analysis.md`

If the wedge is missing or still draft-quality, stop and report that
positioning depends on a locked wedge.

## Deliverable

Write `docs/17-positioning.md`.

## Workflow

1. Pick the buyer’s current alternative:
   - a named competitor
   - a status-quo workflow
   - an adjacent category they buy today by mistake
2. Define the category claim:
   - “the X for Y who Z”
3. Build the value hierarchy:
   - outcome
   - mechanism
   - proof
4. Write and score multiple headline candidates.
5. Choose one concise value prop and a 3-line elevator pitch.
6. Specify hero copy:
   - eyebrow
   - headline
   - sub-headline
   - primary CTA
   - secondary CTA
   - visual brief
7. Write exactly three feature blocks tied to wedge workflow steps.
8. Define anti-positioning:
   - what category this is not
   - who it is not for
   - what it does not do
9. Lock a voice and tone profile.
10. Produce a reusable snippet bank for landing page, OG tags, email, and empty states.

## Quality bar

- avoid generic “AI-powered platform” phrasing
- keep the headline concise
- state buyer outcome, not just product mechanics
- do not claim benefits on the anti-axis
- if a competitor could swap logos and reuse the copy, it is too weak
